# Joanna Chen · Portfolio

Static portfolio and AI Product Lab, prepared for GitHub Pages.

## Publish
Settings → Pages → Deploy from a branch → main → /(root).

## Maintain
Edit the root portfolio files and `ai-product-lab/` in the same repository. Publishing updates keeps the same URL. The old ChatGPT-hosted sites are separate and remain available.

## Demo boundaries
AI Product Lab currently uses browser-local rules, simulated samples and human review; it does not call a live model. Both walkthrough videos use synthetic narration and original synthesized background music.
